
## Completed Exercises: 1.6–1.11
## What I Have Done

I created a React application called Unicafe using Vite.

The application allows users to give feedback by clicking three buttons: Good, Neutral, and Bad.

I implemented the following features:
## Exercise 1.6:** Created feedback buttons and counters using React state.
## Exercise 1.7:** Calculated total feedback, average score, and percentage of positive feedback.
## Exercise 1.8:** Created a separate Statistics component.
## Exercise 1.9:** Used conditional rendering to show statistics only after feedback is given.
## Exercise 1.10:** Created reusable Button and StatisticLine components.
## Exercise 1.11:** Displayed the statistics in an HTML table.

## What I Have Learned

Through these exercises, I learned how to:
Create a React project using Vite.
 Use the useState hook to manage application state.
 Handle button clicks using event handlers.
 Pass data between components using props.
Create reusable React components.

## How to Run the Application

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address displayed in the terminal.
